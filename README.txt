E30HEAVEN V1
============
Static website package.

Files:
- index.html       Main site + working V1 configurator
- hero.jpg         Hero image
- e30-preview.png  Configurator preview
- CNAME             Custom domain: e30heaven.com

Deploy:
1. Create a GitHub repository.
2. Upload all files to the repository root.
3. Enable GitHub Pages from Settings > Pages.
4. Set the custom domain to e30heaven.com.
5. Point the domain DNS to GitHub Pages according to GitHub's current custom-domain instructions.

Future upgrade path:
Keep the front-end in this repository. Add a backend/database later for accounts,
saved builds, garages, forum, marketplace, image uploads and moderation.
